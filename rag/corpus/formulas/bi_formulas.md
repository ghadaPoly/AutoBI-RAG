
# Formules BI — Business Intelligence

## 1. Somme (SUM)

Calcule le total des valeurs numériques.

Formule :
SUM = Somme de toutes les valeurs.

## 2. Moyenne (MEAN)

Calcule la valeur moyenne d'une colonne numérique.

Formule :
MEAN = Somme des valeurs / Nombre de valeurs non manquantes.

## 3. Comptage (COUNT)

Compte le nombre de valeurs non manquantes.

Formule :
COUNT = Nombre de valeurs non nulles.

## 4. Valeurs distinctes (NUNIQUE)

Compte le nombre de valeurs différentes.

Formule :
NUNIQUE = Nombre de valeurs uniques non nulles.

## 5. Minimum (MIN)

Retourne la plus petite valeur d'une colonne comparable.

## 6. Maximum (MAX)

Retourne la plus grande valeur d'une colonne comparable.

## 7. Croissance entre deux périodes

Formule :
Growth Rate (%) = ((Valeur actuelle - Valeur précédente) / Valeur précédente) * 100.

Attention :
Si la valeur précédente est égale à zéro, le taux de croissance ne peut pas être calculé directement.

## 8. Panier moyen

Formule :
Average Order Value = Chiffre d'affaires / Nombre de transactions.

Attention :
Le nombre de transactions doit être supérieur à zéro.
